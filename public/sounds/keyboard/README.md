These files are excerpts of the original key recordings, converted to mono
44.1 kHz PCM WAV for browser compatibility, with each key's peak normalized
to -3 dBFS for audible playback. No synthesized tones, pitch
changes, or noise generation are used.

Each pack contains ten independently recorded keys. `source-config.json`
retains that pack's original per-key offsets and durations. The MIT notice
in this directory applies to all bundled packs. Samples are loaded locally
on first use and cached separately per pack and audio context.
