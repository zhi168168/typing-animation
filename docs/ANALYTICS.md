# GA4 编辑器访问、导出点击与来源分析

当前数据流：`G-FZKLY4DMFE`，正式域名 `typing-animation.com`。

## 已接入的事件

| 事件名称 | 触发条件 | 用途 |
| --- | --- | --- |
| `page_view` | GA4 常规页面浏览 | 查看全站页面访问 |
| `editor_view` | 打开编辑器并允许分析后，每次页面加载最多一次 | 编辑器访问人数/次数 |
| `export_animation_click` | 点击编辑器顶部 Export animation 按钮，包括点击按钮内的图标 | 点击人数/次数 |

点击事件表示打开导出窗口，不表示付款成功或文件下载成功。自动恢复导出弹窗、付款返回、付款校验失败打开弹窗，都不算点击顶部按钮。

“事件数”是次数，“用户总数”是 GA4 去重后估计的人数。同一人点五次，事件数可能是五，而用户总数为一。GA4 基于浏览器/设备标识统计，清除 Cookie、使用不同浏览器或设备时，可能识别为不同用户；这些不是可识别姓名的个人档案。

## 在 GA4 中查看

1. 打开该网站的 GA4 属性，在“报告 → 实时”中检查事件。真实访问者允许分析并进入编辑器或点击按钮后，可检查这两个事件是否出现。常规报告/探索有处理延迟，通常需要 24–48 小时；若没有事件，先检查分析授权、广告拦截和浏览器网络请求。
2. 进入“探索 → 自由形式”，新建探索，命名“编辑器访问与导出来源”。
3. 导入维度“会话来源/媒介（Session source / medium）”及“事件名称（Event name）”；导入指标“用户总数（Total users）”和“事件数（Event count）”。
4. 将“会话来源/媒介”放入行，“事件名称”放入列，将两个指标放入值。
5. 添加过滤器：“事件名称”匹配正则表达式 `^(editor_view|export_animation_click)$`，并选择上线之后的日期范围。

每一行就是一个访问来源，两列分别显示编辑器访问与按钮点击的人数和次数。不需要创建自定义维度，也不需要先把点击事件标为关键事件。

会话来源/媒介回答“这次访问从哪里来”；“首次用户来源/媒介（First user source / medium）”回答“这个浏览器第一次是从哪里来”。本需求建议使用前者。用户可能在不同会话从不同来源回来，各来源行的用户数不宜直接相加当作全站去重人数。

例如 `google / organic` 代表 Google 自然搜索；`(direct) / (none)` 通常代表直接进入或无法识别来源，并不保证用户手动输入了网址。没有历史事件可供追溯，新增事件从本次上线后开始累计。

## 自己发布的推广链接

Google 自然搜索、保留 Referrer 的普通外链由 GA4 识别；公众号、聊天应用或 App 内浏览器可能丢失 Referrer，自己发布的链接建议加 UTM。

X 的推广文章示例：

`https://typing-animation.com/editor?utm_source=x&utm_medium=social&utm_campaign=editor_launch&utm_content=post_01`

公众号文章示例：

`https://typing-animation.com/editor?utm_source=wechat&utm_medium=social&utm_campaign=editor_launch&utm_content=article_01`

- `utm_source`：平台来源，例如 `x`、`wechat`。
- `utm_medium`：渠道类型，例如 `social`、`email`、`referral`、`cpc`。
- `utm_campaign`：推广活动，例如 `editor_launch`。
- `utm_content`：区分同一活动中的不同文章或广告。

标签使用英文、数字、下划线或连字符，单项不超过 100 个字符。代码还允许空格、点和波浪线。不要填姓名、邮箱、订单号或其他个人信息。只给对外推广链接加 UTM，不要给首页到编辑器等站内链接加 UTM，以免干扰来源分析。

可将“会话广告系列（Session campaign）”或“会话手动广告内容（Session manual ad content）”加入探索，进一步区分活动或文章。这些都是 GA4 的内置维度。

## 授权和数据范围

分析仅在访客允许后加载；拒绝分析的访问和点击不发送、不事后补报。广告拦截、网络失败等也会造成漏记，因此 GA4 不等同于全部真实访客数或业务数据库。

保留白名单 UTM 参数用于来源归因；账号令牌、付款/订单标识及其他查询参数和 URL 片段不会随页面地址发送。来源页面的查询参数也会移除。事件不发送动画文字、导出文件、账户邮箱或姓名。

单次访问的来源会由 GA4 与事件关联，无需在点击事件中重新拼装来源，也无需新增自定义用户身份关联。
