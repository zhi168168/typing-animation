# 参考站调研与实现记录

调研日期：2026-10-22。参考：https://www.typeflow.studio/editor 。基于公开编辑器实际交互，未登录、未取得参考站源代码。

## 功能设计

参考站把即时预览与参数设置分开：左侧画布/模式切换/时间轴/播放控制，右侧可滚动参数区和固定导出入口。参数包括文字、录制输入、字体、字重、斜体、字号、颜色、对齐、位置、输入间隔、速度变化、标点停顿、开始/结束延迟、音效、光标和视频设置。

实际观察到：默认 41 字符示例、200 字符上限、80 ms/char、JetBrains Mono、50 px、1280×720、60 FPS；录制输入、音效、光标样式和透明背景等选项呈锁定状态。点击导出显示登录要求，故无法证实参考站导出文件的编码或实际画质。手写模式使用独立字体/写入速度/文字方向设置；笔画实现方式不可从公开 UI 确定。

## 技术实现

React + Vite 构建原生控件 UI；Canvas 统一渲染。Intl.Segmenter 以组合字素切分 Emoji。时间轴预计算每字出现时刻，用二分查找定位当前字数。随机速度采用固定函数，保证反复播放与导出一致。使用完整文字布局提前确定换行，避免打字过程中整体反复跳动。

视频逐帧在浏览器绘制后提交给本机 Express 服务，FFmpeg 分别编码 VP9 WebM 或 H.264 MP4。透明背景保留 PNG alpha 并编码为 yuva420p。导出支持进度、取消及临时文件清理。所有脚本和字体均可本机运行，不依赖第三方线上 API。

## 视觉对照

参考站实际截图作为布局依据；当前环境未提供图片生成工具，未生成额外概念图。采用原站可识别的画布/参数/播放骨架，按本地产品需求进行中文化与设置页签整理，不主张像素级复刻。

对照检查包括：双栏与手机上下布局、画布比例、界面与画布字体层级、深色表面/边框、紫色操作强调、时间轴/播放组、设置控件间距与弹窗。已修复画布高度约束造成留边及桌面整页高度溢出。新增的中文提示、24 个模板、免登录项目保存是明确的本地版本差异；首屏没有营销区、无关导航或统计指标。

浏览器验证使用 Codex 内置浏览器；其普通截图对模拟尺寸有裁切问题，因此通过同一浏览器支持的 CDP 截图取得 1440×900 / 390×844 原始尺寸图。仅临时改变设备尺寸，检查后恢复。未用外部 Playwright 替代。
