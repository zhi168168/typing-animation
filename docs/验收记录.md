## 视觉验证与差异记录

设计依据是用户提供的参考站实际编辑器，而非另行生成的概念图。当前环境没有可调用的图片生成工具，这一限制已提前说明。参考站导出被登录拦截，仅调研公开 UI，没有声称取得其源代码或验证其导出编码。

使用内置浏览器访问参考站及本地应用。常规截图在模拟尺寸下发生裁切，改用同一浏览器提供的 CDP 截图取得原始 1440×900 与 390×844 图像；没有使用外部 Playwright。参考截图和最终本地截图均经 view_image 直接检查。

| 对照点 | 参考依据 | 本地结果与处理 |
| --- | --- | --- |
| 主界面结构 | 左侧画布、下方时间轴、右侧设置 | 保留双栏骨架；无需营销首页 |
| 参数信息结构 | 右侧长滚动列表 | 主动整理为文字/样式/动画/画布四页签，是明确设计差异 |
| 画布比例 | 中央固定比例预览 | 修复高度限制导致的留边，桌面及手机均保持比例 |
| 页面高度 | 桌面编辑器占满窗口 | 修复 Grid 子项最小高度造成的整页溢出；1440×900 时 scrollWidth=1440、scrollHeight=900 |
| 字体层级 | 画布大文字、紧凑界面文字 | 画布与界面字号分别定义；系统字体中文回退；不依赖在线字体 |
| 色彩 | 深色工作台、黑色画布 | 保留深色工作台，使用紫色操作强调与更柔和的示例画布；属于主动视觉调整 |
| 预览控制 | 播放、跳转、时间轴 | 实现并验证，增加循环/空格快捷键 |
| 首屏文案 | 原站英文设置、登录与分享 | 中文化；增加本机保存和模板入口；移除未实现的账号/云分享入口；无未经实现的功能按钮 |
| 模板 | 原站独立模板入口 | 24 个可编辑本机模板，无外部图片资产 |
| 手机 | 原站提示优先桌面使用 | 本地使用上下分区，390×844 下检查文字/样式/画布操作，无横向溢出 |

本版已按参考站的核心编辑结构完成实现与视觉核对，不主张像素级复制。修复了画布留边、桌面高度溢出、颜色输入不可编辑、录制节奏标点重复加停顿、快速导出末字符可能缺失、弹窗焦点与临时文件触发开发页刷新等问题。当前未发现阻碍首版使用的视觉问题。

## 明确边界

- 没有手写笔画动画、账号/订阅、云分享和云端项目库。
- 打字音效仅预览，导出视频不含音频。
- 视频输出单轮，循环用于预览和 HTML。
- WebM 透明视频的剪辑软件兼容性需按目标软件确认；尚未逐一测试 Premiere、Final Cut 等。
- 手机验证是桌面浏览器的尺寸模拟，没有声称完成真实 iOS/Android 设备测试。
- 项目使用系统字体；跨设备 HTML 可能发生字体替换。
- 编码器包为 Windows x64；其他系统需要替换对应二进制。

交付预览图：`typeflow-preview.png`。参考站完整结构与功能映射另见项目内 `docs/对标与实现.md`，启动方式见 `README.md`。
